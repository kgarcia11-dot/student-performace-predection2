# Student Performance Prediction System

A classroom prototype (Data Mining Laboratory) that estimates whether a student is **at risk of failing the final Mathematics grade**. Built with **Python**, **GitHub** and **Streamlit**.

> **Responsible use:** classroom demonstration on public, historical data. Predictions are not diagnoses and must not be the sole basis for real student decisions.

## Problem
Academic risk is often noticed only after poor results. This prototype explores early identification of students who may need extra support, using indicators such as study time, absences, past failures, and the period grades G1 and G2.

## Dataset
[UCI Machine Learning Repository – Student Performance](https://archive.ics.uci.edu/dataset/320/student+performance), fetched with `ucimlrepo` (ID 320).

## Prediction target
| Rule | Label |
|---|---|
| `G3 < 10` | **AT RISK** (1) |
| `G3 >= 10` | **NOT AT RISK** (0) |

`G3` only defines the target and is never used as an input feature (no target leakage).

## Technologies
Python 3.10+ · pandas · scikit-learn (Random Forest) · joblib · Streamlit · Git/GitHub

## Files
| File | Purpose |
|---|---|
| `train_model.py` | Downloads data, preprocesses, trains, evaluates, saves the model |
| `app.py` | Streamlit app: dataset summary, model scores, CSV upload, predictions, download |
| `requirements.txt` | Python dependencies |
| `.streamlit/config.toml` | App colour theme |
| `student_data.csv`, `student_model.pkl`, `model_metrics.json` | Generated by `train_model.py` (included so the app runs immediately) |

## Run locally
```bash
pip install -r requirements.txt
python train_model.py        # creates the CSV, model and metrics
streamlit run app.py         # opens http://localhost:8501
```
In the app: download the sample input CSV → upload it → review predictions → download results.

## Limitations
- Trained on one Portuguese secondary-school dataset; may not generalize to other institutions.
- G1 and G2 are strong predictors, so the model is most useful late in the term.
- Small dataset: do not rely on accuracy alone; check recall for the *At risk* class.
- Uploaded CSVs must be comma-separated and contain the same predictor columns as the training data.
